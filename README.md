# AI Math Differentiator

An interactive web application leveraging Artificial Intelligence to adapt mathematical tasks into 3 distinct difficulty levels (Foundation, Standard, Advanced) for differentiated learning.

## Live Demo
- **Live URL:** https://rococo-souffle-a021a6.netlify.app

## Features
- **Level 1 (Foundation):** Simplified context, step-by-step guided breakdown, and direct hints.
- **Level 2 (Standard):** Standard curriculum grade-level quadratic equation problems.
- **Level 3 (Advanced):** Real-world applications and multi-step optimization challenges.
